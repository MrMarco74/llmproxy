🔒 Ollama-Lock (GPU freiräumen)

Sperrt den Zugriff auf lokale Ollama-Modelle und entlädt sie sofort aus dem VRAM — z.B. um beide GPUs exklusiv für ComfyUI freizuräumen. Clients von /v1/chat/completions mit Frontier-Fallback (fallback.yaml) werden dabei weiterhin bedient. Die nativen Ollama-Endpunkte (/api/chat, /api/generate) kennen diesen Fallback bewusst nicht und werden hart mit 503 blockiert, auch wenn der Client Frontier-Fallback konfiguriert hat — Ollama-Lock ist eine gezielte Sperre, kein Ausfall. Der Zustand übersteht einen Neustart des Proxys. Wird außerdem automatisch gesetzt, solange ComfyUIs Queue nicht leer ist — der Schalter hier überschreibt das jederzeit manuell.

🔎 Splunk Export

HTTP Event Collector (HEC)

Sends every event that already goes to audit.log (guardrail hits, redirects, admin actions, ...) to a Splunk HEC endpoint over HTTPS in addition to the local file — non-blocking, so a Splunk outage never slows down inference.

🔌 Wake-on-LAN (dana)

Wenn eine Anfrage wegen lokaler Nichterreichbarkeit auf ein Frontier-Modell umgeleitet wird (siehe Fallback-Tab), sendet der Proxy automatisch ein Magic Packet an dana, um sie möglichst schnell wieder aufzuwecken — begrenzt durch ein Cooldown, damit nicht bei jeder Anfrage während des Boot-Vorgangs erneut gesendet wird.
