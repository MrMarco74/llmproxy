LLM Monitor & llmproxy — Überblick

Alles was du wissen musst: Architektur, Monitor-App, Installation.

🏗 Wie das zusammenhängt
Dein Rechner / Roo Cline / Open WebUI | | :11435 <-- immer dieser Port, nie :11434 direkt! v +--------------------------------------------+ | llmproxy (, systemd) | | - Logging aller Anfragen (SQLite) | | - Gaming-Mode-Sperre | | - Inference-Budget pro Client | | - Idle Model Eviction | | - /status/stream (SSE live feed) | +--------------------------------------------+ | | :11434 (intern) v Ollama (lokal auf )
✗ http://<gpu-host>:11434 — direkt zu Ollama, nicht verwenden — kein Logging, keine Sperre, kein Budget
✓ http://<proxy-host>:11435 — llmproxy, immer dieser Port

Der Proxy leitet die Anfrage intern an Ollama weiter — für deine Clients ist er vollständig transparent. Alle Ollama-kompatiblen Tools (Roo Cline, Open WebUI, llmbenchy, …) funktionieren ohne Anpassung, du änderst nur die URL von :11434 auf :11435.

⚡ <proxy-host> fährt automatisch hoch

llmproxy läuft auf <proxy-host> als systemd-Service und startet automatisch mit dem System — du musst nichts manuell starten.

Status prüfen
systemctl status llmproxy
Logs ansehen
journalctl -u llmproxy -f
Neu starten
systemctl restart llmproxy
Health-Check
curl <proxy-host>:11435/health
🖥 Was der LLM Monitor zeigt & kann
🎮
Gaming-Mode-Anzeige
Sobald Steam auf dem <gpu-host> läuft, sperrt llmproxy alle LLM-Anfragen und der Monitor zeigt einen roten „GAMING MODE"-Banner. Anfragen liefern dann HTTP 503.
🖥️
Hardware-Live-Stats
CPU-Auslastung, RAM-Nutzung, sowie pro GPU: Auslastung in %, VRAM belegt/gesamt als Balken, Temperatur in °C — alles live via SSE, kein SSH nötig.
🤖
Geladene Modelle
Welche Modelle gerade im VRAM liegen, mit Größe und Context-Länge. Farbkodierung nach VRAM-Anteil (grün → gelb → rot).
📊
Token-Statistiken (Session)
Tokens In/Out seit Programmstart, aktuelle tokens/s (In und Out getrennt), Peak-tps. Wird aus dem Live-Feed akkumuliert.
🔔
Benachrichtigungen (Tray-Toast)
Neue Notifications aus dem llmproxy (Gaming-Mode, Budget-Warnung, TPS-Anomalie, Eviction …) erscheinen als Desktop-Toast. Das Tray-Icon zeigt einen Badge bei ungelesenen Meldungen.
🔗
Verbindungsstatus & Reconnect
Zeigt ob der SSE-Stream aktiv ist. Bei Verbindungsabbruch reconnected die App automatisch alle 3 Sekunden.
📥
Minimize-to-Tray
Fenster schließen versteckt den Monitor im Tray — läuft weiter im Hintergrund. Tray-Icon: Klick = Fenster öffnen, Rechtsklick = Menü mit „Anzeigen" und „Beenden".

⚡ One-Liner Installation

Auf dem Zielrechner ausführen — lädt, entpackt und installiert automatisch:

mkdir -p /tmp/llm-monitor && cd /tmp/llm-monitor && curl -fsSL http://{{ request.headers.get('host', ':18080') }}/static/llm-monitor-setup.tar.gz | tar xz && bash install_monitor.sh --url {{ proxy_url }}
📋 Manuelle Installation
  1. 1
    Archiv herunterladen & entpacken
    mkdir -p /tmp/llm-monitor && cd /tmp/llm-monitor
curl -fsSL http://{{ request.headers.get('host', ':18080') }}/static/llm-monitor-setup.tar.gz | tar xz
  2. 2
    Installer ausführen
    bash install_monitor.sh --url {{ proxy_url }}

    --url muss auf den llmproxy zeigen. Voreingestellt: {{ proxy_url }}

  3. 3
    App starten
    Anwendungsmenü → LLM Monitor
    Terminal: llm-monitor
⚙️ Konfiguration

Die URL wird beim ersten Start gespeichert in
~/.config/llmproxy/monitor.conf

{{ proxy_url }}

Andere URL? Installer mit --url http://<host>:11435 aufrufen.

🗑 Deinstallation
bash /tmp/uninstall_monitor.sh

Entfernt alle installierten Dateien, den Desktop-Eintrag und das Icon.
